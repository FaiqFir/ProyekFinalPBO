# SILap (Sistem Informasi Laptop)

Aplikasi manajemen katalog dan inventaris laptop berbasis desktop.

---

## Download & Instalasi

### Windows
[![Download Windows](https://img.shields.io/badge/Download-Windows%20(.exe)-blue?logo=windows)](https://github.com/FaiqFir/ProyekFinalPBO/releases/download/v5.0/Setup-SILap-Windows-x86_64.exe)

1. Download file `.exe` di atas
2. Jalankan installer
3. Ikuti langkah instalasi

### Linux (AppImage)
[![Download Linux](https://img.shields.io/badge/Download-Linux%20(.AppImage)-orange?logo=linux)]([sha256:3984b62b318bdd0a334e7bb06b23c5b7a479d652e7e9185eeb5cf1f8e863cbe5](https://github.com/FaiqFir/ProyekFinalPBO/releases/download/v5.0/SILap-Linux-x86_64.AppImage))

1. Download file `.AppImage` di atas
2. Beri izin eksekusi:
```bash
   chmod +x SiLap.AppImage
   ./SiLap.AppImage
```
