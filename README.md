# SILap (Sistem Informasi Laptop)

Aplikasi manajemen katalog dan inventaris laptop berbasis desktop.

---

## Download & Instalasi

### Windows
[![Download Windows](https://img.shields.io/badge/Download-Windows%20(.exe)-blue?logo=windows)](sha256:9563aca23e831fed8bba3a26ac7fe1f29e3f7cbc8908829cd214be47be51cd26)

1. Download file `.exe` di atas
2. Jalankan installer
3. Ikuti langkah instalasi

### Linux (AppImage)
[![Download Linux](https://img.shields.io/badge/Download-Linux%20(.AppImage)-orange?logo=linux)](sha256:3984b62b318bdd0a334e7bb06b23c5b7a479d652e7e9185eeb5cf1f8e863cbe5)

1. Download file `.AppImage` di atas
2. Beri izin eksekusi:
```bash
   chmod +x SiLap.AppImage
   ./SiLap.AppImage
```
